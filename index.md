The **crypto-exchange-api-catalog** helps you find and organize cryptocurrency exchange APIs. It turns API data into searchable SQLite databases and JSON specs. Whether you're managing data or generating code, this tool supports multi-vendor systems, REST/WebSocket mapping, and audit trails. You can start with well-known exchanges like Coinbase and expand to others.
